Creation

Functions

getTime

timerUtil.getTime()

Returns the current time of the timer as a Number

reset

timerUtil.reset()

This will reset the time elapsed

hasTimeElapsed

timerUtil.hasTimeElapsed(1000)
​
//or
​
timerUtil.hasTimeElapsed(1000, true)

Returns true if the timer has elapsed the specified time

Parameter Type Description time Number The time elapsed to check in milliseconds reset (Optional) Boolean Set to true if you want to reset the time elapsed if the method returned true
